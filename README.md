Sales Performance Analysis

Project Overview

This SQL project analyzes sales data to identify top-performing products, employees, and customers. The goal is to generate insights that can support better business decisions.

Tools Used

• SQL
• SQLite
• DB Browser for SQLite

Key Business Questions

• Which products generate the highest revenue?
• Which employees perform best in sales?
• Who are the top customers?
• What are the monthly sales trends?

Skills Demonstrated

• SQL queries
• Aggregate functions
• GROUP BY and HAVING
• JOIN operations
• Common Table Expressions (CTEs)
• Window functions

Conclusion

This project demonstrates how SQL can be used to analyze sales performance and extract useful business insights from data.
